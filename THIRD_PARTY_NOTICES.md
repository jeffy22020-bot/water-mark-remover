# Third-party components

The Windows installer bundles the following components. Each one keeps its own license.

| Component | Used for | License |
| --- | --- | --- |
| [LaMa](https://github.com/advimman/lama) inpainting model (ONNX export from the [OpenCV model zoo](https://github.com/opencv/opencv_zoo/tree/main/models/inpainting_lama)) | AI fill behind watermarks | Apache-2.0 |
| [PP-OCRv3 DB text detector](https://github.com/opencv/opencv_zoo/tree/main/models/text_detection_ppocr) | Finding text watermarks | Apache-2.0 |
| [ONNX Runtime](https://github.com/microsoft/onnxruntime) + DirectML | Running the AI models | MIT |
| [OpenCV](https://opencv.org) | Image processing, Fast mode | Apache-2.0 |
| [FFmpeg](https://ffmpeg.org) (via [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg)) | Video decoding and encoding | GPL-3.0 build (includes x264). FFmpeg source: https://ffmpeg.org/download.html |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | Social-media downloads | Unlicense |
| [pikepdf](https://github.com/pikepdf/pikepdf) / QPDF | Editing PDFs | MPL-2.0 / Apache-2.0 |
| [pypdfium2](https://github.com/pypdfium2-team/pypdfium2) / PDFium | Rendering PDFs | Apache-2.0 / BSD-3-Clause |
| [python-pptx](https://github.com/scanny/python-pptx), [python-docx](https://github.com/python-openxml/python-docx), [lxml](https://lxml.de) | PowerPoint / Word files | MIT / MIT / BSD-3-Clause |
| [Pillow](https://python-pillow.org), [pillow-heif](https://github.com/bigcat88/pillow_heif) (libheif) | Reading and writing images | MIT-CMU / BSD-3-Clause (libheif: LGPL-3.0) |
| [NumPy](https://numpy.org) | Arrays | BSD-3-Clause |
| [FastAPI](https://fastapi.tiangolo.com), [Starlette](https://www.starlette.io), [Uvicorn](https://www.uvicorn.org) | Local app server | MIT / BSD-3-Clause |
| [pywebview](https://pywebview.flowrl.com) + Microsoft Edge WebView2 | App window | BSD-3-Clause / Microsoft software license |
| [Python](https://www.python.org) | Runtime | PSF License |

All sample files under "Try one of these" are generated by `scripts/make_samples.py`. They are drawn procedurally and contain no third-party images.
